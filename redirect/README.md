# หน้าแจ้งย้ายเว็บ + redirect อัตโนมัติ

ชุดไฟล์นี้ไม่เกี่ยวกับเว็บทริปกวางโจว — แยกไว้ในโฟลเดอร์ `redirect/`
ต่างหาก ใช้กับ "เว็บเก่า" ที่ต้องการเด้ง popup บอกว่าย้ายไปเว็บใหม่แล้ว

**เว็บใหม่ที่ตั้งค่าไว้:** `http://agg2.egat.co.th/`
**นับถอยหลัง:** 5 วินาที แล้ววิ่งไปเอง (กดปุ่มไปก่อนก็ได้ หรือกดยกเลิกก็ได้)

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | ใช้ทำอะไร |
| --- | --- |
| `index.html` | หน้าที่อยู่ **ข้างใน iframe** — ข้อความแจ้งย้าย + ปุ่ม + นับถอยหลัง |
| `embed-snippet.html` | โค้ดที่เอาไปวางใน **เว็บเก่า** เพื่อเปิด popup ที่ครอบ iframe นั้น |

## วิธีใช้ (3 ขั้น)

1. อัปโหลด `index.html` ขึ้นเว็บเก่า ให้เข้าถึงได้ที่
   `https://เว็บเก่าของคุณ/redirect/index.html`
2. เปิด `embed-snippet.html` ก๊อปเนื้อหาทั้งไฟล์ (ตั้งแต่ `<div id="site-moved-popup"`
   ถึงบรรทัดสุดท้าย) ไปวาง **ก่อน `</body>`** ของหน้าเว็บเก่า
   ถ้าเว็บเก่ามีไฟล์ footer/template ร่วมกันทุกหน้า วางที่ไฟล์นั้นไฟล์เดียวพอ
3. เปิดเว็บเก่าดู — popup จะเด้งขึ้นทันที นับถอยหลัง 5 วินาที แล้วไปเว็บใหม่

## จุดที่แก้ค่าได้

**เปลี่ยนเว็บปลายทาง / จำนวนวินาที** — แก้ 2 ที่ให้ตรงกัน:

- `index.html` ในส่วน `---- ตั้งค่าได้ตรงนี้ ----`
  ```js
  var TARGET_URL = "http://agg2.egat.co.th/";
  var SECONDS    = 5;
  ```
- `embed-snippet.html` ในส่วน `---- ตั้งค่า ----`
  ```js
  var POPUP_SRC = "/redirect/index.html";
  var NEW_URL   = "http://agg2.egat.co.th/";
  ```

ถ้าไม่อยากแก้ไฟล์ `index.html` ส่งค่าผ่าน URL ของ iframe แทนก็ได้:
`/redirect/index.html?url=https://example.com&sec=8`
(`sec=0` คือไม่ต้องนับ วิ่งไปทันที)

## เรื่องที่ต้องรู้ (ไม่งั้นจะงงว่าทำไมไม่วิ่ง)

- **iframe เปลี่ยนหน้าให้ทั้งเว็บได้ก็ต่อเมื่อได้รับอนุญาต** โค้ดไล่ลอง 3 วิธี
  ตามลำดับ: ส่ง `postMessage` ให้เว็บเก่าพาไปเอง (ตัวรับอยู่ใน
  `embed-snippet.html` แล้ว) → เขียน `window.top` ตรง ๆ (ได้เมื่อ iframe กับ
  เว็บเก่าอยู่โดเมนเดียวกัน) → ถ้าไม่ได้จริง ๆ ก็เปลี่ยนหน้าในกรอบ iframe เอง
  **วางไฟล์ทั้งสองไว้บนโดเมนเดียวกันจะชัวร์ที่สุด**
- ปุ่มและลิงก์ที่ผู้ใช้กดเองใช้ `target="_top"` จึงพาไปทั้งหน้าเสมอ
  ไม่ว่าจะข้ามโดเมนหรือไม่
- เว็บใหม่เป็น `http://` (ไม่ใช่ https) ถ้าเว็บเก่าเป็น https เบราว์เซอร์อาจ
  เตือนเรื่อง mixed content ตอนกดลิงก์ — การเปลี่ยนหน้าทั้งหน้ายังทำงานได้
  แต่ถ้าเว็บใหม่รองรับ https อยู่แล้ว แนะนำให้เปลี่ยนค่าเป็น `https://`
- popup นี้เด้งทุกครั้งที่เปิดเว็บเก่าโดยตั้งใจ (เว็บย้ายถาวร ไม่ควรจำว่าเคยปิดไปแล้ว)

## ทดสอบในเครื่องก่อน

```bash
python3 -m http.server 8123
```
แล้วเปิด `http://localhost:8123/redirect/index.html` ดูหน้า popup เดี่ยว ๆ
หรือเปิดหน้าเว็บเก่าที่วาง snippet แล้ว เพื่อดูของจริงทั้งชุด
