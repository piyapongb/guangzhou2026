# หน้าแจ้งย้ายเว็บ + redirect อัตโนมัติ

ชุดไฟล์นี้ไม่เกี่ยวกับเว็บทริปกวางโจว — แยกไว้ในโฟลเดอร์ `redirect/`
ต่างหาก ใช้กับ "เว็บเก่า" ที่ต้องการเด้ง popup บอกว่าย้ายไปเว็บใหม่แล้ว

**เว็บใหม่ที่ตั้งค่าไว้:** `http://agg2.egat.co.th/`
**นับถอยหลัง:** 5 วินาที แล้ววิ่งไปเอง (กดปุ่มไปก่อนก็ได้ หรือกดยกเลิกก็ได้)

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | ใช้ทำอะไร |
| --- | --- |
| `index.html` | **ไฟล์หลัก ไฟล์เดียวจบ** เอาไปวางที่เครื่องไหนก็ได้ เช่น `192.168.1.8` |
| `embed-snippet.html` | โค้ดเสริมฝั่งเว็บเก่า — ไม่ใส่ก็ใช้ได้ แต่ใส่แล้ว auto ทำงานชัวร์ |

## วิธีใช้ (2 ขั้น)

1. เอา `index.html` ไปวางที่เครื่องที่ต้องการ ให้เปิดได้ที่
   `http://192.168.1.8/index.html`
2. เอา URL นั้นไปใส่เป็น `src` ของ iframe popup ในเว็บเก่า
   ```html
   <iframe src="http://192.168.1.8/index.html"
           width="520" height="420" frameborder="0"></iframe>
   ```

เปิดเว็บเก่า → popup เด้ง → นับถอยหลัง 5 วิ → ไปเว็บใหม่

## ⚠ ข้อจำกัดสำคัญ: auto redirect ข้ามเครื่อง

พอ `index.html` อยู่คนละโดเมน/คนละเครื่องกับเว็บเก่า (เช่นอยู่ที่
`192.168.1.8` แต่เว็บเก่าอยู่อีกที่) **เบราว์เซอร์จะไม่ยอมให้หน้าใน iframe
สั่งเปลี่ยนหน้าเว็บแม่เองอัตโนมัติ** เป็นกฎความปลอดภัยของเบราว์เซอร์
กันเว็บโฆษณาลากคนไปที่อื่น — ไม่มีวิธีเลี่ยงตรง ๆ และไม่ควรเลี่ยง

สิ่งที่ทำงานได้ / ไม่ได้ ในกรณีข้ามเครื่อง:

| การกระทำ | ผล |
| --- | --- |
| ผู้ใช้**กดปุ่ม/กดลิงก์**เอง | ✅ ไปเว็บใหม่ทั้งหน้า ปกติ (ใช้ `target="_top"`) |
| ครบ 5 วิ แล้วไป**เอง** | ❌ ถูกบล็อก — เว้นแต่ทำตามข้อ 1 หรือ 2 ด้านล่าง |

โค้ดรับมือไว้แล้ว: ถ้าโดนบล็อก จะขึ้นข้อความสีเหลืองบอกให้กดปุ่ม
พร้อมปุ่มกะพริบให้เห็นชัด (ไม่ใช่ค้างเงียบ ๆ)

### วิธีทำให้ auto ทำงานได้จริง — เลือกอย่างใดอย่างหนึ่ง

**1. เพิ่มโค้ด 10 บรรทัดในเว็บเก่า (แนะนำ — ได้ผลแน่นอน แม้อยู่คนละเครื่อง)**
เปิด `embed-snippet.html` ก๊อป **ก้อน A** ไปวางก่อน `</body>` ของเว็บเก่า
หน้า popup จะส่งสัญญาณมาบอก แล้วเว็บเก่าเป็นคนพาตัวเองไป จึงไม่ติดข้อจำกัดนี้

**2. วาง `index.html` ไว้บนเว็บเก่าเอง (โดเมนเดียวกัน)**
เช่น `https://เว็บเก่า/redirect/index.html` แล้วชี้ iframe ไปที่นั่น
กรณีนี้ auto ทำงานทันทีโดยไม่ต้องแก้อะไรเพิ่ม

**3. ถ้าแก้เว็บเก่าไม่ได้เลย**
เปิด `index.html` แก้ `ON_BLOCKED` จาก `"button"` เป็น `"inframe"`
พอครบ 5 วิ จะโหลดเว็บใหม่ขึ้นมาในกรอบ popup แทน (auto จริง แต่เว็บใหม่
จะอยู่ในกรอบเล็ก ไม่เต็มหน้าจอ)

## จุดที่แก้ค่าได้ (อยู่ใน `index.html` ส่วน "ตั้งค่าได้ตรงนี้")

```js
var TARGET_URL = "http://agg2.egat.co.th/";  // เว็บใหม่
var SECONDS    = 5;                          // นับกี่วินาที (0 = ไปทันที)
var ON_BLOCKED = "button";                   // "button" หรือ "inframe"
```

ไม่อยากแก้ไฟล์ ส่งค่าผ่าน URL ตอนใส่ใน iframe ก็ได้:
`http://192.168.1.8/index.html?url=https://example.com&sec=8`

## เรื่องอื่นที่ควรรู้

- **ถ้า iframe ในเว็บเก่ามี `sandbox`** ต้องมี
  `allow-scripts allow-top-navigation-by-user-activation` ไม่งั้นแม้แต่
  ปุ่มที่ผู้ใช้กดเองก็จะไม่ทำงาน
- **`192.168.1.8` เปิดได้เฉพาะคนในวงแลนเดียวกัน** ถ้าเว็บเก่ามีคนนอกเข้ามาดู
  ด้วย เขาจะเห็น popup ว่างเปล่าเพราะโหลด iframe ไม่ได้ — กรณีนั้นต้องวางไฟล์
  บนเครื่องที่คนนอกเข้าถึงได้
- **เว็บใหม่เป็น `http://`** ถ้าเว็บเก่าเป็น `https://` เบราว์เซอร์อาจเตือน
  mixed content ถ้า agg2 รองรับ https อยู่แล้ว แนะนำให้เปลี่ยนเป็น `https://`
- popup นี้เด้งทุกครั้งที่เปิดเว็บเก่าโดยตั้งใจ (เว็บย้ายถาวร ไม่ควรจำว่าเคยปิดแล้ว)

## ทดสอบในเครื่องก่อน

```bash
python3 -m http.server 8123
```
แล้วเปิด `http://localhost:8123/redirect/index.html` — เปิดตรง ๆ แบบนี้ไม่มี
ข้อจำกัดเรื่อง iframe จะเห็นมันนับถอยหลังแล้ววิ่งไปเว็บใหม่จริง ๆ
