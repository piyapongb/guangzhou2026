# หน้าแจ้งย้ายเว็บ + redirect อัตโนมัติ

ชุดไฟล์นี้ไม่เกี่ยวกับเว็บทริปกวางโจว — แยกไว้ในโฟลเดอร์ `redirect/`
ต่างหาก ใช้กับ "เว็บเก่า" (Mambo) ที่ต้องการเด้ง popup บอกว่าย้ายเว็บแล้ว

**เว็บใหม่ที่ตั้งค่าไว้:** `http://agg2.egat.co.th/`
**นับถอยหลัง:** 5 วินาที แล้ววิ่งไปเอง (กดปุ่มไปก่อนก็ได้ หรือกดยกเลิกก็ได้)

## ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | ใช้ทำอะไร |
| --- | --- |
| `index.html` | **ไฟล์หลัก ไฟล์เดียวจบ** เอาไปวางที่ไหนก็ได้ แล้วเอา URL ไปใส่ใน popup module |
| `embed-snippet.html` | โค้ดเสริมฝั่งเว็บเก่า — ใส่เฉพาะบางกรณี (ดูตารางด้านล่าง) |

## ใช้กับ Mambo popup module

Mambo popup module มี 2 แบบ ผลต่างกันมาก ดูก่อนว่าของคุณเป็นแบบไหน
(เปิดเว็บเก่าดู ถ้า popup โผล่เป็นกล่องทับอยู่บนหน้าเดิม = iframe /
ถ้าเด้งเป็นหน้าต่างเบราว์เซอร์ใหม่แยกออกมา = window.open)

| แบบของ module | auto 5 วิ ทำงานไหม | ต้องทำอะไรเพิ่ม |
| --- | --- | --- |
| หน้าต่างใหม่ (`window.open`) | ✅ ทำงาน | ไม่ต้องทำอะไรเลย |
| iframe + ไฟล์อยู่โดเมนเดียวกับเว็บเก่า | ✅ ทำงาน | ไม่ต้องทำอะไรเลย |
| iframe + ไฟล์อยู่คนละเครื่อง (192.168.1.8) | ❌ โดนบล็อก | เลือก 1 ใน 3 วิธีด้านล่าง |

### แนะนำ: วางไฟล์ไว้บนเว็บเก่าเลย (จบในตัว ไม่ต้องแก้โค้ดอะไร)

ก๊อป `index.html` ไปวางที่ docroot ของ Mambo (โฟลเดอร์เดียวกับ
`index.php` ของเว็บเก่า) ตั้งชื่อว่า `moved.html` แล้วตั้ง URL ใน popup
module เป็น

```
/moved.html
```

โดเมนเดียวกัน = เบราว์เซอร์ยอมให้เปลี่ยนหน้าอัตโนมัติ auto ทำงานทันที
ตั้งขนาด popup ประมาณ **520 x 420** กำลังสวย

### ถ้ายืนยันจะวางไว้ที่ 192.168.1.8 และ module เป็นแบบ iframe

ตั้ง URL ใน popup module เป็น `http://192.168.1.8/index.html` แล้วเลือก
วิธีให้ auto ทำงาน 1 ใน 3:

1. **เพิ่มโค้ด 10 บรรทัดในเว็บเก่า (ได้ผลแน่นอน)**
   เปิด `embed-snippet.html` ก๊อป **ก้อน A** ไปวางก่อน `</body>` ใน
   `templates/<ชื่อ template ที่ใช้อยู่>/index.php`
   **⚠ อย่าวางผ่าน editor ของ Mambo** — TinyMCE จะลบ `<script>` ทิ้งเงียบ ๆ
   ถ้าจำเป็นต้องใส่ผ่านหน้าเว็บ ให้ไปตั้ง Site Settings → Default WYSIWYG
   Editor → **No Editor** ก่อน แล้วค่อยวางใน module แบบ Custom HTML
2. **ย้ายไฟล์ไปไว้บนเว็บเก่า** ตามหัวข้อ "แนะนำ" ข้างบน
3. **แก้เว็บเก่าไม่ได้เลย** → เปิด `index.html` เปลี่ยน `ON_BLOCKED` จาก
   `"button"` เป็น `"inframe"` พอครบ 5 วิ จะโหลดเว็บใหม่ขึ้นมาในกรอบ popup
   แทน (auto จริง แต่เว็บใหม่จะอยู่ในกรอบเล็ก ไม่เต็มหน้าจอ)

## ทำไม iframe ข้ามเครื่องถึงโดนบล็อก

เบราว์เซอร์ไม่ยอมให้หน้าที่อยู่ใน iframe คนละโดเมน สั่งเปลี่ยนหน้าเว็บแม่
เองอัตโนมัติ เป็นกฎความปลอดภัยกันเว็บโฆษณาลากคนไปที่อื่น — เลี่ยงตรง ๆ
ไม่ได้และไม่ควรเลี่ยง สิ่งที่ยังทำได้คือ **ผู้ใช้กดปุ่มเอง** (ใช้
`target="_top"`) ซึ่งทำงานปกติทุกกรณี

โค้ดรับมือไว้แล้ว ไม่ค้างเงียบ ๆ — ถ้าโดนบล็อกจะขึ้นแถบเหลืองบอกให้กดปุ่ม
พร้อมทำปุ่มกะพริบให้เห็นชัด

(กรณี `window.open` ไม่ติดกฎนี้ เพราะเบราว์เซอร์ยอมให้หน้าต่าง popup
สั่งหน้าต่างที่เปิดมันขึ้นมาได้ โค้ดจึงพาเว็บเก่าไปเว็บใหม่แล้วปิดตัวเองทิ้ง)

## จุดที่แก้ค่าได้ (อยู่ใน `index.html` ส่วน "ตั้งค่าได้ตรงนี้")

```js
var TARGET_URL = "http://agg2.egat.co.th/";  // เว็บใหม่
var SECONDS    = 5;                          // นับกี่วินาที (0 = ไปทันที)
var ON_BLOCKED = "button";                   // "button" หรือ "inframe"
```

ไม่อยากแก้ไฟล์ ส่งค่าผ่าน URL ตอนใส่ใน popup module ก็ได้:
`http://192.168.1.8/index.html?url=https://example.com&sec=8`

## เรื่องอื่นที่ควรรู้

- **ถ้า iframe ของ module มี `sandbox`** ต้องมี
  `allow-scripts allow-top-navigation-by-user-activation` ไม่งั้นแม้แต่
  ปุ่มที่ผู้ใช้กดเองก็จะไม่ทำงาน
- **`192.168.1.8` เปิดได้เฉพาะคนในวงแลน** ถ้าเว็บเก่ามีคนนอกเข้ามาดูด้วย
  เขาจะเห็น popup ว่างเปล่าเพราะโหลดไม่ได้ — อีกเหตุผลที่ควรวางไฟล์ไว้บน
  เว็บเก่าเอง
- **เว็บใหม่เป็น `http://`** ถ้าเว็บเก่าเป็น `https://` เบราว์เซอร์อาจเตือน
  mixed content ถ้า agg2 รองรับ https อยู่แล้ว แนะนำให้เปลี่ยนเป็น `https://`
- **ตัวบล็อก popup ของเบราว์เซอร์** มีผลเฉพาะ module แบบ `window.open`
  ถ้าเว็บเก่าสั่งเปิดเองตอนโหลดหน้า (ไม่ได้เกิดจากคนกด) เบราว์เซอร์อาจบล็อก
  หน้าต่างนั้นตั้งแต่แรก — เป็นข้อจำกัดของตัว module เอง ไม่ใช่ของไฟล์นี้
- popup นี้เด้งทุกครั้งที่เปิดเว็บเก่าโดยตั้งใจ (เว็บย้ายถาวร ไม่ควรจำว่าเคยปิดแล้ว)

## ทดสอบก่อนใช้จริง

```bash
python3 -m http.server 8123
```
แล้วเปิด `http://localhost:8123/redirect/index.html` — เปิดตรง ๆ แบบนี้ไม่มี
ข้อจำกัดเรื่อง iframe จะเห็นมันนับถอยหลังแล้ววิ่งไปเว็บใหม่จริง ๆ
